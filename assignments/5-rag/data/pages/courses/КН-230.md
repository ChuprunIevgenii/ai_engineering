# КН-230 Паралельні обчислення (частина 2)

Факультет: Факультет інформаційних технологій (ФІТ)
Кафедра: Кафедра комп'ютерних наук
Курс: 2
Семестр: осінній
Тип: вибіркова
Кредити ЄКТС: 3
Викладач: Гаврилюк Петро Васильович
Аудиторія: 3.113
Пререквізити: ПЗ-204 «Архітектура програмного забезпечення», КН-190 «Машинне навчання (частина 2)»
