# КН-368 Теорія ймовірностей (семінар)

Факультет: Факультет інформаційних технологій (ФІТ)
Кафедра: Кафедра комп'ютерних наук
Курс: 2
Семестр: весняний
Тип: обов'язкова
Кредити ЄКТС: 3
Викладач: Бондаренко Іван Степанович
Аудиторія: 3.307
Пререквізити: КН-311 «Обробка природної мови», ПЗ-204 «Архітектура програмного забезпечення»
